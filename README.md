🍔 Menu Interativo — Sistema de Pedidos

Um sistema simples e interativo de cardápio desenvolvido em Python, ideal para praticar lógica de programação, estruturas de decisão e interação com o usuário via terminal.


📋 Sobre o Projeto
O Menu Interativo simula um pequeno sistema de atendimento de uma lanchonete diretamente no terminal. O usuário navega por categorias de produtos, escolhe o item desejado, informa a quantidade e recebe o valor total do pedido na hora.
Desenvolvido com foco em simplicidade e clareza de código, é um ótimo projeto para iniciantes que estão aprendendo Python.

▶️ Como executar
Pré-requisitos

Python 3.10+ instalado na máquina (necessário para o uso do match/case)

Digite uma opção: 1

1.Cachorro-quente R$ 20
2.Hamburguer R$ 30

Insira o numero do lanche: 2
Quantos você deseja? 3
O valor total deu: R$ 90.00

🧠 Conceitos utilizados

match/case — estrutura de seleção múltipla (Python 3.10+)
input() — leitura de dados do usuário
if/elif — decisões condicionais
Formatação de strings com f-strings
Operações aritméticas básicas
